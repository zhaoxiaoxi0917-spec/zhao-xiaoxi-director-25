# 表演与声音：让人物对人做事

内容索引：1表演链；2情绪过程与技巧；3台词归属；4时间剪辑；5声场文字。

身体先后、承重与动作句详见17；声音透视、声音事件卡、主观放大、静默、混响与动态详见19，正式分镜声音设计须调用。此文件保留原词与可听归属的基础协议。

## 1. 可演的表演链

内部依次确定：此刻目标 → 对手 → 策略 → 潜台词 → 改变策略的触发 → 外显行动 → 没能完全压住的余波。输出只保留本镜需要的部分，不把整张心理分析表塞进Prompt。

“愤怒、悲伤、震惊”只能标方向，不能替代导戏。用针对对手的动作动词，如试探、稳住、逼退、诱导、遮掩、讨价还价、确认、切断。外显动作必须由人物当下可获得的信息触发。

例：“她要确认对方是否撒谎。先看文件，再抬眼等他回答；听到否认后不追问，原本准备伸向文件的手停在桌边。”比“极度震惊、眼神复杂、演技炸裂”更可执行。若剧情没有文件或伸手行为，不为套此例添加。

## 2. 给选择，不逐帧操纵演员

- 每个关键节拍选择少量主导信号：眼神目标、呼吸/语速、姿态或手部行为。不要给每秒眨眼次数、每个音节的眉毛角度、每镜固定三种微表情。
- 沉默也要有对象和任务，例如等对方承认、压住追问、装作没听见；不把沉默写成无动作、无呼吸、凝固的照片。
- 不默认全部人物隐忍低声。区分其掩饰方式、节奏、社会姿态和关系中的惯用策略。喜剧可直给，崩溃可外放，权威也可通过速度和打断建立，服从项目表演尺度。
- 情绪变化可以只改变一次选择，不必立刻落泪、跪下或大吼。哭、笑和身体反应需要剧情或表演设计支持。
- 人物的身体、年龄、衣物、伤势不应随情绪自行变形；剧本明确的附体、变身或超自然身体变化则按事实保留。
- 听者镜头可主动承载情绪、关系评价、共情与压力传递，不以立刻采取新行动为门槛。重要信息、羞辱、威胁、亲人支持、身体阻拦和证据变化之后，逐一判断谁最需要被看见，再比较独立反应镜与同镜观察。不要平均分配每人每句反打，但重要反应不能仅留画外、背景虚影或扫过侧影便算完成。

表演设计不填“演员＋影片＋模仿方法”，不要求人物演成某演员的某个角色。以本段情绪过程、人物任务和表演技巧作为依据。以下技巧受过程导向导演方法启发，是向AI可见行为的转译，不声称模型有演员的内在体验。

### 2.1 先确定情绪怎样发生

为关键人物确定起点、刺激、想保护／得到什么、策略改变及结束时尚未消失的情绪。情绪可以并存：愤怒中仍期待被承认，恐惧中故意强硬，轻松里藏着试探；不能把每句台词都调到同一最高强度。

“强化表演”应强化意图、触发、节奏差异和可见选择，让短剧观众读得出，不等于只增音量、瞪眼、抽泣。关键转折需要接收与变化时间；反应须明确刺激、对象、试图维持的状态、压不住的变化及余波，即使镜尾人物仍未采取新行动。角色不能在关键字尚未传来就先开始反应。

### 2.2 从可演技巧中选择，不一次堆满

| 技巧 | 导演可给的任务 | 可见／可听落实 | 常见误用 |
|---|---|---|---|
| 行动动词／对象 | 逼对方承认、安抚、拦住、试探、遮掩、切断 | 句子向谁发出，希望对方接着做什么 | “表现悲伤”没有行动方向 |
| 倾听与接收 | 接收事实、承受羞辱或感受支持，可暂不改变行动 | 原期待／试图维持的状态→刺激到达→压不住的变化→情绪或关系余波 | 提前反应；把背景模糊人影当作已完成表演 |
| 潜台词与反向行动 | 表面宣布规则，实际要掩盖害怕 | 字句硬、身体仍守住退路；余波暴露代价 | 要求演员同时演出六种抽象心理 |
| 身体任务 | 维持摊掌等待、守住门区、停止伸手 | 通过已存在的动作／道具表达控制或犹豫 | 为了有戏临时加杯子、烟或文件 |
| 冲动与抑制 | 想追问／向前，但选择停住 | 起势、短暂停住、转换策略；有明确对象 | 每次都攥拳咬唇当统一标点 |
| 呼吸与声音行动 | 争取说完、压住颤音、突然切断辩解 | 气息、句间空隙、咬字、力度和句尾变化 | 每句前吸气；用抢读装不下的台词 |
| 节奏与停顿 | 让对手等回答，或在被逼问时急于填空 | 停在对手可接收的位置，下一句随选择开始 | 以省略号代替真实等待任务 |
| 地位与关系距离 | 拒绝让路、迫使对方看自己、主动解除接触 | 站坐、朝向、视线对象、让路／挡路 | 未排路线便写“压迫感强大” |
| 想象条件／仿佛 | 供导演准备时理解此刻代价 | 转成片内行为与关系，不写入虚构事实 | 给角色添加未经剧本许可的创伤历史 |
| 情绪遮掩后的泄露 | 维持礼貌但已无法继续请求 | 一次未完成的笑、收手、重置呼吸或一句失去原语气 | 每镜都“眼含泪光、微微颤抖” |

每个节拍选最有用的技巧与少量信号；这是选择菜单，不是每人每镜必填十项。演员对手关系先于孤立表情，听者在画外也继续任务。

### 2.3 如何把导戏写进Prompt

“本场导演设计”说明哪项表演变化值得留下、镜头如何捕捉；人设栏写当前对手任务；逐镜只展开正在发生的刺激、行动与声画余波。导演给真人演员可保留开放空间；生成Prompt则需要把决定性结果转成少量可见行动，二者不能混为“逐帧操控”。

弱：借鉴某演员在某片中由隐忍转愤怒，眼神复杂。

可执行：她原本要对方承认自己的居住资格，手掌仍朝上等待交付；听见公开排斥后，先维持看着对方的目光，想继续争取，准备说的话却没有出来。她收回手，下一句从请求改成举事实质问，咬字更明确；不是突然以尖叫接替上一句。此例只在剧情已有相应动作与台词时采用。

### 隐瞒身份或知情时的双重任务

装病、卧底、隐瞒身份、假装不知情等情境，分别确定“真实要获取／确认什么”与“要让谁相信自己仍是什么状态”。按已知剧情设计：刺激到达 → 想观察或反应的冲动 → 为不暴露而抑制／转移 → 对手实际能看见什么 → 镜尾秘密是否仍被保住。以少量可见信号实现，不把每次压抑都演成瞪眼或攥拳。

摄影机看见不等于对手看见。核对遮挡、朝向、距离和声音，区分观众可读的泄露与片内对手可察觉的泄露；不能靠“对方没发现”一句话掩盖正面对视、可听惊呼等矛盾。保密成功、被察觉或双方互知均须服从原稿阶段，不能自主添加。

微动作可与对白并行；检查是否妨碍发声／口型、争夺必要观看或挤掉重要反应时间，不笼统禁止动作占用对白期间。原稿未规定的细节只补实现所需部分，不把每次拿物扩成机械十步。

### 2.4 表演幅度按戏选择，不统一压低

下列是情绪与任务的组合示意，不是固定动作包；只采用当前剧本许可的行为。

- **受辱后的反击**：起初仍争取被承认，公开排斥使请求失效；身体先停止迎合，下一句转成逼问。情绪可明显外露，声音的力度与节奏改变比统一大吼更有层次。
- **恐惧中的强硬**：人物怕被识破，任务却是让众人服从；先过快填补沉默，见到对手不退才提高音量或打断。提高声音是策略，句尾与守路姿态仍泄露恐惧，不突然恢复完全平静。
- **紧急保护**：危险一旦被确认，允许立即高声、急促呼吸和大幅行动，注意力直指需要保护的人或危险源。不要为了克制美感让人物慢吞吞看一圈，关键救援动作与结果须可见。
- **悲痛失去控制**：刺激确实突破承受后，可以哭出声音、说不成整句或失去原有姿态；冻结对白仍完整，给足恢复呼吸和完成句子的时间。不是每镜换一滴泪，也不删掉剧本要求的崩溃。
- **喜悦或喜剧掩饰**：先让人物真想取得某个结果，再让过度认真、错拍、误会或短暂失守产生效果；不只指定“喜剧表情”。喜悦的身体打开、节奏加快也应有具体对象与触发。

把表演幅度与前后镜连起来：强势人物先当众发言，到点名时才把注意力全集中到一人身上，构图随之从一桌人收向两个人。若原稿写当众崩溃，就让人物的音量和身体失去原有控制，在能容纳动作的景别拍足；若写隐忍，一次未完成的接物可以比接连叹气更能说明代价。用前镜蓄势、转折镜改变行动、后镜承受后果。

## 3. 台词冻结与声音归属

逐句登记原文、说话人、语言、顺序、现场/画外/旁白等声音类型与触发。不要为了秒数缩写、换同义词、补称呼、翻译或合并句子。确需改写时先给建议，不混进冻结稿。

OS含义不明确且影响人物是否听见时询问；不能一概当内心独白。现场画外声音可被场内人物听见；旁白或内心声是否被听见须依剧本，而不是依角色是否出镜猜测。

表演、语气、声线描述放在台词正文之外。例如“林岚压低音量，向沈舟确认，现场对白：{你确定？}”。不要把“冷笑”“林岚说”“女声”写入花括号让其成为正文。

说话人可不出镜；出镜人未必说话。旁听者有自然呼吸、吞咽和反应，不需要“所有非说话人嘴唇焊死”。多人抢话、合唱等原文明确的重叠可保留，逐一标声源与可见口型；普通对话则避免无依据地同时说。

声线连续性可记录年龄感、音域、质感、口音、速度和当前用力状态，但音频参考不存在时不伪造。项目若区分身体声线、意识声线或电话滤波，按当前设定，不引入旧项目规则。

## 4. 时间与声画剪辑

先估读台词，再安排可并行的动作、不可并行的动作和必要停顿。语速范围见02；情绪、口音和拖音会改变结果，数字只能预算，最终需试听。

| 手段 | 时间关系 | 适用目的 |
|---|---|---|
| J-cut | 下一画面的声音先进入，随后切到下一画面 | 先听见威胁/来人，声音引出空间 |
| L-cut | 已切到下一画面，上一画面的声音仍延续 | 看听者承受正在说出的内容 |
| 声桥 | 声音联系前后段，可连续或形成意义关联 | 连贯过场、建立因果或反差 |
| 声音留白 | 有意降低某些声音，保留必要环境/呼吸或真正静音 | 聚焦主观感受；须说明范围 |

可让原句尾音延续到听者画面，提前把观看交给反应，既保留原速对白，也为接收、变化和余波争取时间；不把反应总排成台词结束后的剩余秒数。一条台词跨镜时是一条声音事件，不重复启动两遍。在起点写一次完整原句，后镜注明同一次发声延续到何处。制作说明中给起止时间和切画时点。

原生音画生成能表达上述意图，不保证逐帧完成精确剪辑。精确切点可交后期；若改用后期配音，说明口型同步、声音表演与重定时的额外工作，不能承诺无损自动对齐。

## 5. 声场、音乐与文字

将现场对白、画外对白、旁白、环境、动作声、配乐分清。声音可提供画外空间、先兆、力度和主观距离，不只是给每个动作加大音效。

按19给关键声音写声源结构/材质、触发相位、听觉视点、远近与遮挡、起音/持续/衰减、前后层次与恢复点。主观听觉可改变观众听到的比例，不能让片内其他人无因听见放大的微声。“骤然安静”须明确是真实声源停止、选择性抽离、相对静默或全混音静音；不能同时完全静音又保留呼吸。声音进入设计阶段可先于机位选择，不靠新增心跳或配乐替代声场组织。

声音随距离、门窗阻隔和人物方位合理改变；反打不必将房间底噪换成另一个空间。电话端是否露脸由信息设计决定，不为“电话戏完整”暴露未知来电者。避免背景人声抢走被冻结对白。

按项目声音约定设计；本项目禁配乐时，用场内声的远近、停顿或一次动作声组织节奏。用户明确要求配乐时再设计进入、退出和对白的层次。

字幕、画内道具文字与平台水印分属不同问题。未要求不新增字幕；已有招牌、短信、文件文字按剧情和参考处理，不一律改英文或抹掉所有文字。关键精确文字若生成不稳，保留其叙事功能并提出可执行的后期替换方案，不直接删剧情。特定分隔符不是已证实的字幕控制API。

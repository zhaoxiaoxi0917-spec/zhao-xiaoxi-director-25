# 赵小惜导演台 2.5

**面向 Seedance 2.5 的 AI 短剧导演 Skill：从读懂剧本，到排演动作、设计画面，再交付可执行的九栏分镜 Prompt。**

由 **cecil** 维护。技能版本 **v1.14**；本次发布包整理日期：**2026-11-13**。

## 项目介绍

赵小惜导演台 2.5 是一套面向 AI 短剧创作的导演工作流，涵盖剧本研读、场面调度、演员表演、摄影光影、声音设计、分镜编写与成片返修。

它从人物的目标、关系和行动出发，先判断一场戏最值得拍下的瞬间，再安排演员如何行动、观众何时看见、摄影机怎样靠近，以及声音如何改变观看体验。美学会落实到空间、色调、材质、光源和具体镜头；人物站位、视线、接触动作与道具流转则贯穿整个段落。

面对文学剧本，它将文字转为可拍摄、可剪辑的画面；面对已有分镜或生成失败的片段，它从首次偏离的位置查找原因，重新组织受影响的动作、镜头和段间衔接。在保留原台词、关键事件与剧情结果的前提下，为导演判断提供充分的创作空间。

适合 AI 短剧导演、编剧、分镜师和制作团队，用于从剧本到提示词的创作与复核。

## 核心能力

| 能力 | 具体工作 |
|---|---|
| 剧本研读与节拍划分 | 梳理目标、策略、信息差、人物知情边界与戏剧转折，核算台词和动作时间 |
| 动作排演与场面调度 | 展开起态、触发、承重、运动路径、接触、解除与结束姿态，检查人物和道具是否可达 |
| 美学与质感设计 | 选择适配的美学传统和成像方案，写清空间造型、光色、材质、颗粒、运动模糊及其可见结果 |
| 摄影与功能补镜 | 设计景别、毫米焦距、光圈、清晰范围、机位和运动；为重要反应、动作结果、空间连接补足观察 |
| 表演与声音设计 | 为角色安排对手任务与情绪变化；组织声源材质、远近遮挡、听觉视点、声音层次和声画衔接 |
| 身份与连续性管理 | 核对人物身份、画面左右、相对空间、前中后景、道具持有者及跨段状态 |
| 九栏分镜编译 | 将导演判断整理为完整、独立可读的制作 Prompt，保留原对白及其发声归属 |
| 诊断、返修与学习 | 定位生成问题，重建受影响段落；支持影视术语、摄影技法和参考片段的学习与原创迁移 |

内含 **20 份参考模块、164 项视听技法、19 类场景调度案例、12 部影视作品的美学研究条目**，以及一份完整九栏教学案例。资料按任务调用，不要求每次全部读入。

## 工作方法

1. **读本。** 确认本次实际可读材料、人物关系、原对白、关键行动及首尾状态。
2. **排戏。** 在已知场景中预演人物、道具与声音，检查行动因果和空间可达性。
3. **构想画面。** 选出核心瞬间，用具体的构图、光色、表演和声画关系组织观看。
4. **拆镜与补镜。** 为必须看清的行动、反应和结果安排镜位，写明运镜触发、路径与停点。
5. **编译与核对。** 分配时长，形成九栏 Prompt，对回原稿并检查前后段接口。
6. **依据成片返修。** 有实际视频和声音时，再判断口型、身份、接触、表演与剪辑是否成立。

## 默认制作约定

| 项目 | 默认值或处理方式 |
|---|---|
| 目标模型 | Seedance 2.5 |
| 媒介与画幅 | 真人短剧、9:16；输入明确其他媒介时按项目调整 |
| 段落时长 | 每段固定 30 秒的制作规划；平台入口能力需另行确认 |
| 描述语言 | 中文制作描述；对白按原稿语言保留，英语原稿逐字冻结 |
| 镜头数量 | 根据节拍、动作与对白预算确定；常规多人戏以约 8—12 镜复查覆盖，不机械凑镜数 |
| 声音与文字 | 默认保留原剧本声音与同步环境／动作声；不额外添加对白、旁白、配乐、字幕或水印 |
| 素材绑定 | 仅引用实际提供且已确认的素材，不虚构角色、场景或平台标签 |
| 返修交付 | 默认交付完整目标段；明确要求只改某镜时，提供该镜及必要衔接 |

上述是工作约定。时长、分辨率、素材数量和生成能力，以实际使用的平台及版本为准。焦距、光圈、时间码等描述表达导演意图与验收目标。

## 九栏输出结构

| 栏目 | 内容 |
|---|---|
| 本场导演设计 | 首幅画面、核心表演、转折与镜头落点 |
| 生成任务 | 模型、媒介、画幅、时长、镜数和语言规则 |
| 视觉风格 | 美学路线、成像基准、光色、材质与声音基调 |
| 场景 | 已确认的空间结构、门窗通道、背景、光源和时段 |
| 人设 | 人物身份、识别点、本集状态、目标与表演触发 |
| 道具 | 形制、数量、持有者、初态和必要用途 |
| 站位调度 | 画面方位、相对位置、前中后景、关系轴与运动起终点 |
| 镜头 | 逐镜时间、摄影、完整画面描述、声音／人声 |
| 本段锁定 | 下段必须继承的人物、空间、道具、知情和声音状态 |

完整示例见 [导演构镜与九栏成品示例](skills/zhao-xiaoxi-director-25/references/08-worked-examples.md)。示例属于原创文字预演，未附视频生成实测。

将仓库中的整个 [`skills/zhao-xiaoxi-director-25`](skills/zhao-xiaoxi-director-25/) 文件夹复制到所需作用域，保留其中所有子目录：

| macOS / Linux 当前用户 | `~/.agents/skills/zhao-xiaoxi-director-25/` |
| Windows 当前用户 | `%USERPROFILE%\.agents\skills\zhao-xiaoxi-director-25\` |

复制后，`SKILL.md` 应直接位于上述技能目录内。打开技能列表核对名称；Codex CLI / IDE 可用 `/skills` 查找，或在提示中使用 `$zhao-xiaoxi-director-25`。已有同名技能时先比较版本，再决定替换，避免重复安装。

安装位置与调用方式依据 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)，核对日期为 2026-11-13。

### ChatGPT 中调用

在已安装本技能且支持 Skills 的环境中，用 `@` 选择「赵小惜导演台2.5」。本仓库提供技能源文件；GitHub 下载本身不会完成 ChatGPT 账号内的安装。

### 第一次使用

提供目标集剧本、当前可用的人设／场景／道具，以及本次必须保留的修改。如果前后段影响本段起终状态，再补充相关段落。可以使用 [任务输入模板](templates/task-brief.md)。

**从剧本制作分镜：**

```text
使用 $zhao-xiaoxi-director-25。
根据我提供的目标集剧本、人设和场景，完成第 2 集的导演设计与完整九栏分镜 Prompt。
先研读剧本、排演动作，再选择美学、镜位与补镜。
每段固定 30 秒，9:16；段数按我给出的制作要求执行。
保留原英语对白及关键剧情结果，人物、场景、道具、站位分别列出。
```

**返修已有段落：**

```text
使用 $zhao-xiaoxi-director-25 修改我附上的 4-2 段。
开场改为女主单人近景。她站在门内，男主站在门外，双方面对面。
检查开门、递出文件、对方接住、松手四个状态，并承接前后段。
给出完整可替换版本，保留原台词、已确认人设和场景。
```

**学习并迁移技法：**

```text
使用 $zhao-xiaoxi-director-25 分析我提供的参考片段。
重点拆解摄影机的起幅、运动触发、路径、停点，以及声音怎样引导注意力。
区分片段中能直接观察到的事实和你的推断，再把方法迁移到我给出的原创场景。
```

## 能力范围

本项目是一套由语言模型执行的导演知识与工作流。它交付分析、设计、制作 Prompt 和返修方案；图片生成、视频生成、Blender 预演或制作平台提交，需要另行接入相应工具。

包内模型资料保留原有核验日期，属于资料快照。实际制作时应核对所用平台当前规格。文字审查可以检查设计和连续性，口型、身份稳定性及最终成片效果仍需依据实际生成结果判断。

## English overview

**Zhao Xiaoxi Director 2.5** is a Chinese-language filmmaking skill for AI short-drama workflows targeting Seedance 2.5. It turns scripts and production assets into nine-section storyboard prompts through story analysis, action rehearsal, blocking, visual design, cinematography, performance direction, sound design, and continuity review. It preserves the supplied dialogue and story outcomes while supporting creative shot design and targeted revisions. The repository contains the v1.14 skill, 20 reference modules, a worked example, and usage documentation. Video generation requires separate tools.

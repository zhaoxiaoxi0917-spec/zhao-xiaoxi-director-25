# 美学流派、摄影系统与成像术语

目录：1分类；2风格路线；3年代与系统；4摄影术语；5颗粒与运动；6光色材质；7写入分镜；8检查。

用于具体风格选型、机型/年代、毫米焦距、胶片/数字纹理、MB等术语辨析，以及“电影感”过于空泛的返修。常用镜头技法的执行库仍在14，声音术语在19，学习课程及来源在20。下列路线是导演候选，不是每一种流派的完整历史，也不把某种技术与固定情绪一一绑定。

## 1 先分清五层，不把异类标签并列堆叠

| 层次 | 例子 | 必须补充的决定 |
|---|---|---|
| 叙事立场/运动/美学传统 | 意大利新现实主义、德国表现主义、法国新浪潮 | 社会观察、现实变形、时间组织或主观性，怎样作用于本场 |
| 类型与风格传统 | 黑色电影 Film noir、新黑色电影 Neo-noir、情节剧 Melodrama | 人物处境、光影空间、情绪和道德困境；不能只贴滤镜 |
| 制作媒介 | 真人、手绘二维动画、定格、三维动画 | 形体、表面、运动与空间的规则 |
| 摄影/成像系统 | 35mm胶片、Super 16、Super 35数字、大画幅数字 | 机身、成像面积、镜组、胶片/传感器、曝光与后期 |
| 单项技法 | 明暗对照、深焦、分层调度、声画对位 | 本镜什么变化、谁看/听得到、如何起止 |

“手绘电影”先落实为手绘二维动画的线条、上色、背景和运动方法，不能把它当成与新现实主义相同层级的流派。可用新现实主义观察劳动，也可用手绘媒介表现它；组合须说明各层职责。不要给既定真人项目擅自换成动画。

## 2 可调用的风格路线

正式视觉风格写一个主要路线及实际执行规则；需要混合时说明另一方法仅负责哪一维度。专业名称可以出现在Prompt，参考影片、导演和演员姓名仍按09留在研究说明。

| 专业名称 | 本场可以借的机制 | 转成画面/表演 | 不应简化为 |
|---|---|---|---|
| 意大利新现实主义 Italian Neorealism | 日常处境、真实环境与社会关系参与行动 | 让劳动、等待、街道距离影响人物；环境保持可辨，不将所有背景虚化 | 灰色滤镜、破衣服、必定手持；不保证全部使用非职业演员或同期声 |
| 自然主义表演/照明 Naturalism | 行为和受光有生活来源 | 窗光、实景灯和环境反射有空间依据；反应从倾听发生 | 没设计、没有戏剧强度 |
| 黑色电影 Film noir | 困局、欲望、隐瞒及受限制的空间 | 有方向的低调照明、明暗切分、遮挡与深处出口；重要表情仍可读 | 夜景、全黑、每镜百叶窗；黑白不是唯一方式 |
| 新黑色电影 Neo-noir | 延展黑色传统至新的社会与色彩系统 | 在现有场景用局部冷暖、反射、几何分隔制造不安 | 自动霓虹雨夜、紫蓝调色 |
| 德国表现主义 German Expressionism | 空间与造型外化心理 | 在获准美术设计中采用夸张几何、投影和形体关系 | 随意歪斜、乱加阴影；锁定写实场景不能擅改墙体 |
| 法国新浪潮 French New Wave | 自发性、位置感、叙事省略与形式自觉 | 有目的的现场感、跳切或自由时间组织；保留片内身份与信息 | 所有法国电影、任意跳轴；本skill不越轴约定仍优先 |
| 直接电影/真实电影 Direct Cinema / Cinéma vérité | 两种有关联但不能完全等同的纪录实践 | 明确观察还是拍摄者介入；在虚构戏中只借相应观看方法 | 手持就是真实纪录，或两者毫无区别 |
| 社会现实主义 Social realism | 人物选择受劳动、制度与空间制约 | 身体任务、公共空间和群体反应可读 | 穷、暗、脏的统一外观 |
| 情节剧美学 Melodramatic style | 将关系冲突外化为姿态、物件与色光秩序 | 选择有情绪作用的距离、饱和色块、动作停顿及反应 | 一律吼叫、夸张哭泣或随情绪变灯 |
| 超现实主义 Surrealism | 梦、联想、非理性关系与现实断裂 | 明确授权的主观段落中重组物象/时间 | 随机变形、角色身份失控 |
| 形式主义/图形化 Formalist / graphic design | 构图、节奏、形状建立明确规则 | 门框、轴线、色块与动作方向重复后发生变化 | 只求对称而搬动锁定人物 |
| 手绘二维动画 Hand-drawn 2D animation | 线条与关键姿态组织运动 | 锁轮廓、色块、背景笔触，按动作设计原画与中间画的节奏 | 真人叠素描滤镜，或强制所有镜头12fps |
| 赛璐珞动画外观 Cel-animation look | 轮廓和色块与背景绘画分工 | 人物边缘清楚，阴影色块稳定，背景有独立笔触密度 | 声称AI真的逐张拍摄透明胶片 |
| 转描 Rotoscoping | 以真人运动作绘制依据 | 保留动作节奏后设计线条/形体抽象程度 | 自动等于手绘、完全照搬真人脸 |
| 定格 Stop motion | 实体材质与逐格姿态 | 触点、道具尺度、关节位移和表面手工感 | 故意卡顿即可，所有材质都黏土 |
| 绘画式三维动画 Painterly 3D | 三维体积配合受控笔触与非写实着色 | 确定笔触附着表面、线条稳定及光影简化规则 | 笔触随机闪烁、贴纸纹理滑动 |

所有路线先通过剧情和媒介适配，再写光、色、空间、运动和声音。纯洁净数字风格也可以是明确选择；不强加胶片颗粒。

## 3 年代、摄影系统和乳剂分开选

### 3.1 写三个不同的时间

分清故事发生年代、参考制作年代、实际/模拟成像流程。现代数字拍摄可以表现1940年代故事；1980年代机身也可使用后来的胶片。若称“严格复刻某年拍摄系统”，须核对机身、镜头系列、乳剂、冲洗与后期流程的历史可用性；只查机身年份不够。

Panavision **Panaflex Platinum** 是正确拼写（不是 Panaflax）。厂家确认它是同期声35mm胶片摄影机，历史资料将其置于1980年代；法国电影资料馆记录1986年的Platinum。机身负责走片、取景、快门等，不独自决定颗粒、柔焦、饱和度或暖色。[来源20：S01—S03]

### 3.2 系统选择卡

| 路线 | 系统写法 | 适用的表达与限制 |
|---|---|---|
| 1980年代后期35mm制作语汇 | Panaflex Platinum；已核对年代的球面镜组；35mm底片及当时乳剂；24fps与快门角；冲洗/印片意图 | 用完整工艺构建年代语汇；9:16是本项目重构图，不冒称原时代标准放映画幅 |
| 当代35mm胶片意图 | Panaflex Platinum或已核实35mm机身，Primo球面镜组，VISION3 500T 5219等明确乳剂 | 说明是当代胶片组合/AI视觉模拟，不冒充1986年乳剂；镜头风格与胶片风格各自说明 |
| Super 16纪实纹理 | 已核实Super 16机身/画幅及对应胶片，按最终放大倍率设计颗粒 | 可选择较明显纹理和空间观察；不是Super 16自动等于粗糙或低清 |
| Super 35数字观察 | ALEXA 35等已核实系统，实际焦距和画幅、曝光与纹理处理分开 | 数字纹理或后加颗粒明确标注，不称真的使用底片 |
| 全画幅数字精细层次 | VENICE 2等已核实系统与镜组，明确取景和清晰范围 | 机位决定透视；大画幅不自动更高级或更浅景深 |
| 手绘二维 | 构图/虚拟视角意图、线条、上色、背景、动作节奏 | mm只作视角沟通时明确标注，不虚构真实光圈、胶片曝光和传感器 |

历史乳剂示例：Kodak年表列1983年EASTMAN 5294为35mm钨光EI 400胶片；VISION3 5219属于2007年推出的系列。它们不能不加说明地交换年代。使用某款时只引用确证特性，别凭型号编造“固定青影、金肤”。[S04]

### 3.3 选型输出骨架

风格路线＋故事/制作参考年代（相关时）＋成像系统/画幅＋镜头类型/系列＋胶片乳剂或数字纹理流程＋光色/曝光意图＋颗粒/高光/黑位＋帧率/快门与动作模糊＋9:16取景方式。

这是一张内部选择卡，不是每镜复制的参数墙。全段共用项目写第三栏；每镜必须落地焦距、光圈/清晰范围、焦点与构图。每个数字都要与当前空间相容；缺少实测距离时标为设计值，不假装测量。

## 4 摄影术语：名称、单位和可见用途

| 术语 | 含义/单位 | 写进分镜的方法与边界 |
|---|---|---|
| 焦距 Focal length | 镜头光学量，mm | “50mm球面定焦”；不是“焦点50毫米” |
| 对焦目标 Focus target | 此刻最清晰的物或部位 | “焦点留在近侧眼睛，手退出清晰面” |
| 对焦距离 Focus distance | 成像平面至目标的距离，m/cm | 必要时给设计距离；不是镜头前端到人的距离 |
| 成像画幅/Gate/Sensor format | 有效感光/记录区域 | “Super 35画幅实际50mm”；不与全画幅等效混写 |
| 视场角 Field of view | 焦距、画幅、裁切共同决定的取景范围 | 先保证全身/触点，再选mm；9:16裁切会改变可用范围 |
| 35mm胶片规格 Film gauge | 胶片宽度规格 | 与35mm焦距是两件事；Super 35也不是35mm宽传感器的保证 |
| f-number | 几何光圈比值 | 与景深相关但不独自决定景深 |
| T-stop | 透光量标定 | 写T2.8仍需说明清晰范围，不拿它精确计算景深 |
| 景深 Depth of field | 可接受清晰的前后范围 | 指出必须看清的对象；“浅景深”不能让关键手消失 |
| 深焦 Deep focus | 前后重要层同时可读的拍法 | 要有光学/合成依据及主体大小；不是“深背景” |
| 拉焦 Rack focus | 在镜内移动焦平面 | 起焦—触发—过渡—落焦，不漏一次性反应 |
| 焦点呼吸 Focus breathing | 对焦时视角/放大率变化 | 可控制或作为特征；不是演员呼吸 |
| 球面镜头 Spherical lens | 非变形压缩的成像方式 | 不自动产生横向蓝光斑和椭圆散景 |
| 变形宽银幕 Anamorphic | 拍摄压缩与还原的光学方式 | 标压缩比/还原/裁切意图；9:16先核构图，不直接套横幅模板 |
| 散景 Bokeh | 焦外点与过渡的视觉形态 | 分离主体；不能与镜头眩光混同 |
| 镜头眩光 Lens flare | 强光与光学系统产生的散射/反射 | 需相应光源角度；不能凭“旧镜头”自动加一条蓝线 |
| 柔光滤镜 Diffusion filter | 改变高光扩散、微反差等 | 给强度意图与可见结果，不当成皮肤磨皮 |
| ND中性密度 | 减少入射曝光 | 可用于日景大光圈；不必改快门制造错误拖影 |
| EI曝光指数 / ISO | 胶片曝光参考与数字系统感光标定等相关但不全同 | 说明采用哪套系统；改变数字EI的结果依机型，不断言必然增噪 |
| 曝光宽容度 Latitude | 允许的曝光偏差范围 | 与动态范围相关但不等同；不能保证所有阴影和高光无限可救 |
| 动态范围 Dynamic range | 系统可记录/再现的亮暗跨度 | 黑位、布光反差与高光压缩仍须分别设计 |
| 快门角 Shutter angle | 每帧曝光所占周期 | 同一帧率下较小角度通常更短曝光、更少运动模糊 |
| 帧率 Frame rate | 每秒记录/播放帧数 | 慢动作需区分拍摄与播放速率；不能把24fps直接叫慢动作 |

## 5 颗粒、噪声、运动模糊与后期

| 术语 | 定义与执行 | 不要混用 |
|---|---|---|
| 胶片颗粒 Film grain | 胶片影像微观结构形成的可见颗粒感；尺度/密度感受取决于胶片、曝光、处理、扫描及展示 | 不是固定不动的噪点贴图；彩色成像也不能简单称全由残留银粒构成 |
| 数字噪声 Digital noise | 记录系统中的随机或结构性误差；可有亮度/色度成分 | 不是胶片颗粒同义词；不要拿彩色坏点代替胶片纹理 |
| 颗粒尺度/强度/时间性 | 分别写细中粗、可见程度、逐帧自然变化；面部不被吞没 | 无公认跨软件“颗粒30%”；没指定软件不编伪统一参数 |
| 光晕 Halation | 亮部边界的胶片内部光传播/反射相关现象，或后期模拟 | 不等同镜头眩光；强红边不是所有胶片必有 |
| 高光扩散 Bloom | 亮部向周围扩散的视觉效果，可由光学或后期产生 | 不自动证明用了胶片，不让画面整体蒙雾 |
| 高光滚降 Highlight roll-off | 高光过渡到极亮处的呈现 | 是系统/曝光/映射共同结果，不是机身固定滤镜 |
| 门片晃动 Gate weave | 胶片画面定位的细微漂移 | 与颗粒不同；不默认所有胶片画面明显抖动 |
| 划痕/尘点 Scratches/dust | 介质、复制或放映的损伤/污染 | “1980年代”不自动等于破损旧拷贝 |
| 欠曝/迫冲 Underexposure / push processing | 曝光与显影是不同操作，影响色调、反差与颗粒等 | 不用“加ISO”笼统代替；要谈具体乳剂与流程 |
| 留银/跳漂 Bleach bypass | 减少或省略漂白步骤的工艺及其模拟 | 选明乳剂/流程或标模拟；不当成所有黑色电影的必需项 |
| 印片模拟 Print emulation | 模拟印片/放映链条的色调响应 | 不是单个暖色LUT，不声称复制真实物理全流程 |
| 运动模糊 Motion blur | 曝光时物体与镜头相对运动形成的拖影 | 与离焦、低分辨率、鬼影不同；不能全身僵住只给衣服拖影 |
| 滚动快门 Rolling shutter | 不同像素行在不同时间曝光/读取造成的运动形变等 | 全局快门也可有运动模糊，二者不是互斥选项 |
| 拖影/重影 Ghosting | 多帧融合等造成的重复轮廓，具体原因须核验 | 不是正常180°快门必然结果 |
| MB / Mb / Mbps | MB通常表示兆字节；Mbps是码率单位；有些制作语境用MB缩写Motion Blur | 用户只写MB时不擅定含义。涉及动作质感时写全称“运动模糊”；涉及文件则区分容量/码率 |
| Bit depth / Codec / Compression | 位深、编码方式与压缩分别影响记录/交付 | 文件越大不等于画面越“电影”；不在生成词里伪造已输出码率 |

快门关系：曝光时间=快门角/(360×帧率)。24fps、180°约1/48秒；90°约1/96秒。它们是设计/摄影关系，不是所有AI平台支持的物理控制项。短曝光的利落与断续感、长曝光的拖曳需结合动作速度与机位判断。[S07]

胶片纹理写法示例：“35mm负片视觉模拟；中等细度的动态颗粒在中间调可辨，皮肤细节不被覆盖；高亮边缘只有克制扩散，黑位保留深色衣料层次；不添加无剧情依据的划痕与门片晃动。”这是本次审美选择，不是所有35mm胶片固定外观。Kodak对5219的说明强调颗粒感还受场景内容、色彩和密度等影响。[S05]

## 6 光、色和材质的学习词条

| 术语 | 在本场如何使用 | 边界 |
|---|---|---|
| 明暗对照 Chiaroscuro | 用方向性明暗组织体积、隔离或关系 | 并非只把曝光压低 |
| 低调/高调 Low-key / high-key | 组织画面总体亮暗分布与照明关系 | 高调不等于过曝，低调不等于看不清 |
| 硬光/软光 Hard / soft light | 阴影边缘与光源相对尺寸关系 | 软光仍可形成高反差，不与高/低调混同 |
| 动机光 Motivated light | 灯光在世界里有可理解来源 | 可有隐藏的制作补光；项目禁额外脸灯时服从约定 |
| 实景灯 Practical | 画内或布景本身的灯具 | 不一定独自提供足够曝光 |
| 负补光 Negative fill | 减少环境回返，增加暗侧层次 | 不是“给脸打黑色灯” |
| 侧逆光/Rim light | 从侧后方分离轮廓 | 固定光源与机位对应，不让轮廓无因发光 |
| 漫反射/镜面反射 | 粗糙表面与光滑表面对光作不同回应 | 材质描述必须在景别内可见 |
| 光比 Lighting ratio | 指定比较对象的照明比例 | 不与像素亮度、后期对比混用；T值也不是光比 |
| 色温/WB/Tint | 光源光谱特征、白平衡设定和绿洋红校正的不同环节 | 不以一个K数规定所有混合光色彩 |
| 微反差 Microcontrast | 局部细小亮暗的区分 | 不等于锐化轮廓或毛孔放大 |
| 色彩分离 Color separation | 邻近物体/肤色与背景仍可区分 | 不机械套橙青分离 |

## 7 将专业词写入九栏

**视觉风格**选美学路线和全段系统；**场景**说明已有建筑/光源/材质如何支持；**每镜摄影**明确实际毫米焦距、画幅约定、T/f值或明确清晰范围、焦点目标/转焦、机位与运动；**完整描述**让变化在动作中发生；**声音**按19写事件而非清单。

逐镜优先写具体mm与T/f值，并补清晰结果；空间或镜头规格无法确定时，用明确的设计假设/清晰范围而不是编造实测。相同机身、胶片、帧率、快门、白平衡无需逐镜抄写；单镜另行提交须恢复独立执行所需基准。动画的mm/T仅有真实虚拟摄影意义时使用，否则写视角和分层规则。

例：新黑色电影的遮挡与局部明暗；当代35mm胶片视觉模拟，Panaflex Platinum＋Primo球面镜组＋VISION3 500T 5219，24fps/180°，9:16取景。镜头用Super 35画幅意图的50mm、T2.8，人物胸上近景，对焦近侧眼，门后深处只保持位置可辨。墙灯形成既有侧后亮边，面部由环境回返承接。该组合是新设计，不是1980年代原工艺声明，也不保证生成器执行参数。

手绘例：手绘二维动画、明确轮廓与有限阴影色块，背景采用可辨纸纹的水彩层次；移动由前中后景层差组织，手的关键姿态及中间过渡清楚。视角按中等透视设计；纸纹附着背景，不覆盖人物皮肤变成真人颗粒；不同时要求真实镜头散景和所有二维层同样锐利。

## 8 专业性检查

专业不是术语多，而是含义和画面一致。检查：风格类别正确；年代组合不伪造；实际与等效焦距不混；T/f与清晰范围相容；动作速度与快门相容；颗粒/噪声/划痕分开；机身、镜组、胶片、光源和后期各承担正确职责；动画不伪装真实拍摄；去掉形容词仍能执行。未核实的型号规格查官方资料或明确不确定，不编造镜组焦段。

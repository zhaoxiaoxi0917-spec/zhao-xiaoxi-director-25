# 提示词编译与声音协议

正式输出结构、通用约束和逐镜字段统一执行09；美学选择执行11、表演技巧执行05、拆补镜执行12。首栏使用“本场导演设计”，从既有场景、原剧情和演员动作中形成具体画面。

## 1. 两种任务，两种读者

导演说明供人决策，正式Prompt供生成执行。先读懂剧本转折、排演员和机位，选定要保住的瞬间、核心画面与剪辑落点，再写成可见可听的发生过程。不要把台词自检结果、机型／美学选择论证、镜头修改报告、诊断争论、失败历史、评分和备选方案混入正式Prompt；Prompt仍保留执行所需的机型、质感、美学规则与逐镜视听设计。全部Prompt之后另起一行，按09第9节提供台词核对、选型理由与逐集逐段设计说明；用户只要Prompt时不附冗长分析，但仍保留这条简洁结尾，除非用户明确取消。

客观视频标注记录实际可见可听的内容，不补剧情、不猜心理或摄影器材；制作Prompt可以设计有依据的表演、光影、运镜和补镜，但不得更改冻结台词、能力与剧情结果。缺失的音频标为未核实，不能把字幕翻译、转写猜测或第三方自动分析当作逐字听辨。

正式九栏与逐镜模板统一见09。格式与符号是写作约定，不声称是Seedance官方解析语法，也不保证模型按帧执行。


## 2. 符号、主体与真实参考

- {}：实际人声原文，包括现场台词、画外声、内心独白、系统音、歌词；正文外说明说话人、声音类型、口型与语气。
- <>：环境音／动作音效；也用于引用，如<场景1>、<后期包装1>。写<门轴摩擦声>与<场景1>，靠明确语义区分；不能把音效当作人物台词。
- （）：音乐/BGM及其变化；无音乐时段头写“无配乐”，镜头中不要为了填符号新增音乐。
- 【】：实际应出现在画面里的文字／字幕；内容不自动朗读。
- 主体标签直接使用人物名字，如<ELENA>、<ARTHUR>，不要让有名角色始终写成<主体1>或<ID1>。无名人物用稳定角色称谓，群像沿用整体英文称谓，如<Guards>；独立画外声用<系统音>、<匿名来电者>。如用户另有ID协议，首次给出ID与姓名映射。
- 真实素材引用采用用户/平台实际提供的标签，写清锁身份、站位、运镜或质感哪一项。文档里的<场景1>或<林岚>只是引用名称，不等于图片已经上传绑定；未提供参考时直接说明是文字设计。
- 主体在场但不入画时，登记必要画外位置与发声/接触状态，不强迫每镜出现肩膀、倒影或所有角色。

保留用户原台词文字、语言、标点、发言顺序与声音类型。整句只在开始镜完整写一次，跨镜用“同一句继续，当前承载……部分”描述落点，不重复启动；不另设情绪目标栏。


按02先检查常规短剧镜头密度与独立反应，按03逐镜落实三重站位和段界接口，按04落实面对面对切、机位路径、景深和已有声源。运镜不代替剪辑：一个镜头要在同一时刻读清不同方向的人脸、手部或证据而无法兼顾时，必须拆镜；不能仅凭“缓推／拉焦”断言可拍。

## 3. 编写连续镜头

一个镜号只有一个连续摄影镜头。若示例依次“高位俯拍全景→切近俯拍→切低位仰拍”，正式制作要拆成三个镜号，各有独立摄影、完整描述和声音；若需组织镜头组，称“镜头组”，下设镜01/02/03。连续上摇、移焦、移动显露是镜内变化，不因出现新动作自动切镜。

时间码使用生成段内连续时间；有全片时间需求时单独标明偏移，不混用。时间窗互不无意重叠/留空，跨镜音轨可以连续。用户指定30秒则完整覆盖30秒；平台和用户另有规格从其要求，不能为了凑整改台词或拖长反应。

单镜完整描述采用自然段：从该镜最有效的画面或声源开场，以“先、接着、直到、随后”说明动作和相位，最后交代可见结果或稳定停留。后续声音变化写在发生处，不把所有声音堆在段首。镜头有关键对白，逐字声音栏标明台词与动作的时间关系；无台词不填空占位。

微表情选择能读清的一两项，不在一秒堆睫毛、下颌、嘴唇、转头、呼吸六项；手部多阶段任务给足接触、释放和可辨认时间。合镜前逐项检查接触、关键表情、移焦期间不可重复事件、两方向重要事件和听者接收／变化时间；写出“震惊、迟疑、愤怒”不等于已在画面覆盖。重要反应须有可辨取景、焦点与观看时长，不因动作可连续发生便交给一镜包办。把共享机型、镜组、画幅约定、乳剂/数字纹理、帧率快门、白平衡及光向集中在视觉风格栏。真人逐镜明确mm焦距、T/f及清晰范围、焦点目标、景别、机位与运动；不以全段焦段范围代替本镜选择，不伪造测量。动画按18写虚拟视角与媒介规则。声音按19写触发、声源质地、透视层级与变化/接出，不能只列音效名。关键运动交代起幅、触发、可走的路线、途中遮露或焦点变化和收幅。反应镜拍足接收，不能靠转焦遮掉必须看见的接触。


## 4. 连续性、压缩与验收

三重站位采用用户定义：画面边界方位、物体之间相对方位、前中后景层次。摄影机的物理侧别和轴线另外校核，详见03。人物右手与画面右侧不能互相替代；不要靠换角色位置掩盖越轴。

把既往返修转成适用的检查，而非全项目禁令：
- 身高、肤色按本项目有效人设；情绪变化不默认皮肤变红/变白。角色站桌、落地后按支撑更新高度，不能在所有剧里硬套220/180厘米。
- 门口明确开合方向、操作者在哪侧、跨槛先后；摄影机在室内不等于开门人物已在室内。
- 登桌/下桌、牵手/抽手、转交/收袋须有可达路径、支撑与手部归属。物件转移后状态持续，不让下一镜复原。
- 用户指定的动作次数、尚未发生的下一次动作、人物是否露脸/投影/入画等属于当前项目锁定；次数和身份不能由声音尾响、字幕或背景虚影擅自增加。
- 真正的表演和审美由镜头设计承担，不靠通用STYLE堆叠。前缀、后缀、人物、道具、镜头与结束状态必须清除相互冲突的旧指令。

发布前检查初态、动作过程、镜尾结果互相对应，人物与物件状态不能提前写成终态。检查台词与原文双向对照、接触因果、声音归属、位置更新、图像参考是否真实存在。

导演自由仍保留：选长镜或切镜、揭示时机、反应与功能补镜，不以格式强制空镜开头、每句反打或把关键特殊能力删掉。只声明文本审查，模型执行与成片质量需实际生成后另验。

## 6. 编译前的身份与状态检查

先按13统一当前映射、场景和状态，再填九栏。@只在人设栏绑定一次不等于正文省略身份：每镜用姓名标主体，身份易混处自然补当前素材的一两个识别点和位置，不复述所有人履历。参考名称并非平台已收到素材的证据。正式文本中同一字段只能有一个答案，逐段前后核对双手、服装、位置、门灯和知情，不能把更换开场主体当成连续性通过。

# 声音设计：声源、听觉视点、空间与动态

目录：1先设计听什么；2声音事件卡；3术语；4主客观切换；5打火机示例；6其他场面；7写入九栏；8验收。

用于正式分镜的声音层、声音主导的转折、“骤然安静”“微声占满空间”、声画剪辑与声音返修。原词、声音类型和可听范围依05冻结，符号依06，成品格式依09。默认不增加配乐、对白、旁白或有语义群演声；创意主要来自既有声源的选择、层次、动态和时间。

## 1 在定镜头前先决定观众听什么

声音不是画面完成后的逐项贴音。先从原剧本、已有资产和身体行为中选出能改变观看的声音，再排人物听见的时点与摄影切点。[方法参考20：S11；以下为本skill原创执行归纳]

依次回答：
1. 这场原本有哪几层声音？哪层是空间连续的底，哪层必须辨认？
2. 谁发声、谁在片内能听见、观众按谁的距离/注意力听？
3. 声音在何时改变：真实声源停了、空间阻隔改变，还是主观听觉发生转换？
4. 对白、动作瞬态、环境尾声各在什么时候成为前景？
5. 变化之后保留什么、何时恢复、下镜怎样接住？

只用本场真正需要的层，不在每镜机械凑满风声、脚步、呼吸、衣料、心跳和低频轰鸣。用户没给音乐就不能用“音效”名义加持续配乐性音床。

## 2 声音事件卡（内部设计，成品用自然句）

| 字段 | 要确定什么 | 例子 |
|---|---|---|
| 声源与类别 | 哪个具体身体/物件；现场、设备、内心、旁白、环境、拟音等 | 已存在打火机的盖铰链；同步动作声 |
| 触发与相位 | 什么动作开始，是否一次性，何时停止 | 拇指掀盖才有金属轻响，不在握住时先响 |
| 听觉视点 | 客观空间、某人注意力、编辑性强调 | 近距离听物；或明确切入角色主观听觉 |
| 空间 | 方位、近远、遮挡、直达声与反射关系 | 门外左后方；关门后削弱清晰度与高频，但不变成绝对隔音 |
| 音色与包络 | 攻击/起音、持续、衰减；粗糙/尖脆/闷钝等材质 | 短促金属碰击后迅速衰减，不写成大钟长鸣 |
| 动态层次 | 哪一层进入前景、哪层退后，是否掩蔽对白 | 动作声在停顿中突出，下一句起音前退下 |
| 接出 | 尾声跨镜、硬断、衰减、恢复、声桥 | 残响延到听者镜；不在换画时重新敲一次 |

秒数、增益、滤波和混响参数若用于实际后期，标为初始设计值，需试听调整。未指定混音工具与交付标准时，优先用相对层级及可听结果，不虚构声压、精确频点或软件旋钮能被生成器直接执行。

## 3 专业声音术语与调用边界

| 术语 | 机制 | 可执行写法/常见误用 |
|---|---|---|
| 叙事内声 Diegetic sound | 声源属于故事世界 | 片内可听性另核距离；不等于所有人都听见 |
| 叙事外声 Non-diegetic sound | 声源处于故事世界之外，如某些配乐或旁白 | 本项目无授权不新增；不能仅凭现场有无声源归类，画外声和内心声不自动等于叙事外声 |
| 画内/画外声 On-screen / off-screen | 声源此刻是否在画面内 | 画外脚步仍可能是现场声；角色不出镜不代表闭口心声 |
| 主观听觉 Subjective sound / point of audition | 按人物感知选择/变形声音 | 标谁的听觉、触发、变化及退出；不必同为第一人称画面 |
| 声音透视 Sound perspective | 远近、空间、遮挡的听觉关系 | 广角/全景不必机械录成远声，须交代听觉立场 |
| 听觉特写 / sonic close-up | 微小声音在混音中获得前景地位 | 可让打火轮很近，不等于它物理响遍广场 |
| 选择性聆听 Selective listening | 从既有声场突出某一层 | 削弱其他层，保留焦点声；避免所有音效一起变大 |
| 声学环境 Ambience | 环境整体底层及细节 | 写场所、密度、远近与连续性，不只“有环境音” |
| 房间底声 Room tone | 特定室内位置的稳定环境底 | 室外写环境底，不把所有静谧都称room tone |
| 拟音 Foley | 为身体/物件动作制作同步声音的方法 | 脚步、衣料、触碰按实际材质；不是新增动作授权 |
| 音效 SFX / 硬音效 | 可来自现场、素材或设计的声事件 | 写具体来源和时点；“轰”不等于角色做了什么 |
| 瞬态 Transient / 起音 Attack | 声音开始时的短暂变化 | 锁在扣合、击打或落地相位，不能每镜重复 |
| 持续 Sustain / 衰减 Decay | 保持及渐弱的过程 | 火焰持续、金属余响分开；非所有声都同样长 |
| 直达声 Direct sound | 直接到达听者的成分 | 近声清晰可干，但露天不等于绝无反射 |
| 早期反射 Early reflections | 较早到达的空间反射 | 柱廊/墙体支持时使用，不随意把广场混成教堂 |
| 混响 Reverb / 尾响 Tail | 密集反射形成的衰减 | 指长度感与空间，不凭材质名断言确切秒数 |
| 回声 Echo | 可辨识的延迟重复 | 与连续混响不同；注意不误读成第二次动作 |
| 干/湿 Dry / wet | 原声与效果成分的比例关系 | 近干声与远空间层可对比，不用“湿声”暗示真的有水 |
| 遮挡 Occlusion / 低通 Low-pass | 障碍或处理改变频率和清晰度 | 隔门声音需材质、缝隙、距离依据；不保证内容可懂 |
| 声像 Panning / 宽度 Width | 声音横向位置与分布 | 保留声源方向，不让反打一切就跳声像；手机单声道也须可懂 |
| 动态范围 Audio dynamic range | 最弱与最强声音的跨度 | 留空间给突变，不等于全程响亮 |
| 掩蔽 Masking | 某声音使另一声音不易辨认 | 避免点火瞬态遮住唯一关键字 |
| Ducking / 音量自动化 | 随触发降低一层或绘制音量变化 | 点明哪层退、何时恢复；不等同角色听不见 |
| 声音抽离 / drop-out | 特定声层快速退出 | 指定是环境、动作还是全混音；不要笼统“世界静音” |
| 相对静默 Relative silence | 保留极弱底声/呼吸，形成安静感 | 人物停说不等于环境消失 |
| 绝对静音 Digital silence | 指定区间所有目标轨道均无声 | 不能同一时段又写清楚呼吸；不剪掉原稿必须听见的对白 |
| J-cut / L-cut | 声音先于对应画面进入/在画面切出后延续 | 标同一次事件，不能重读台词 |
| 声桥 Sound bridge | 以连续或关联的声音连接镜段 | 不把语义关联误写为同一物理声源 |
| 声画对位 Counterpoint | 画面与声音产生意义差异 | 选择要有剧情功能；不是任意加悲伤音乐 |
| 声音母题 Sonic motif | 相同或变形声音在不同节点形成关联 | 使用既有声源；不能为母题新增关键道具 |
| dBFS / dB SPL / LUFS | 数字电平、声压级、响度测量的不同量 | 没有混音实测不报告数值结果；不将“降低10dB”称为声压测量 |

## 4 “骤然安静”必须选一种成立方式

### A 世界中的真实静止

例如原剧情允许机器停转、门关上或群体停止动作。声音从真实事件改变，角色也能听见改变；环境中不受影响的风、交通或设备应继续。物理声源仍在活动，就不能无说明地静音。

### B 角色的主观听觉抽离

画面中的世界继续运行，但观众暂时按某人的注意力听。写触发、听觉所属者、被抽离的层、保留的声音、持续区间和恢复点。其他人物不因此听见被放大的微声；也不因耳边效果获得原本听不到的秘密。

### C 编辑性强调

短暂突出动作声来组织节奏，不必宣称角色发生创伤或幻听。写“混音中突出”而非强加心理诊断。可以在动作切点留下短暂空白，但不能吞掉冻结对白。

### D 完全静音

明确所有声轨在某个区间归零，尾响是否一并截断，下一声由什么引入。若保留呼吸，就不是完全静音。只在戏剧用途明确且不删原声时使用；不把一切停顿都做成静音。

## 5 原创示例：打火机微声“占据广场”

前提：剧本已有广场、点火者、打火机与本次点火；没有这些资产不能从示例直接增入。下述约8秒是可嵌入30秒段的教学声音设计，不是新增段长或原片复盘。先辨认道具：有盖的燃油棉芯式、丁烷气体式、喷射式，点火/持续/熄灭声不同，不能都套燃气喷声。

以已锁的有盖燃油棉芯式打火机为例：

| 局部时间/触发 | 画面事件 | 声音设计 |
|---|---|---|
| 0—2秒 | 人物停在广场原位，取出已有打火机 | 先建立风与远处无语义人流底声，衣料摩擦处于近层；声场保持空间宽度 |
| 2—3秒，掀盖/打火 | 拇指掀盖，打火轮摩擦并点燃 | 先金属盖短响，再打火轮粗短摩擦和点燃的轻促声；严格按动作相位，不凭火焰出现补一次爆炸 |
| 3—5秒，注意力收束 | 火焰已经稳定，人物注视它 | 明确进入此人的主观听觉：远处人流和风迅速退到近乎不可辨，打火机声成为极近前景；微弱燃烧声被表现性放大。这里是混音选择，不是火焰真的响遍广场 |
| 5—6秒，合盖 | 有盖打火机合上，火焰熄灭 | 金属合盖声短而明确，燃烧层停止；不增加不属于此道具的长喷气声 |
| 6—7秒 | 人物保持未动 | 若用相对静默，仅保留近乎不可辨的室外底；若选择绝对静音则这一区间不保留呼吸/风/尾响，二选一写清 |
| 7—8秒，回到现实任务 | 人物重新看向原有对手/行动方向 | 既有风和远人流恢复到先前透视，恢复由回看/重新行动触发；不新增钟声或一句话充当恢复按钮 |

若打火机是丁烷气体式，只在气流确实属于该结构时写轻微气流声；按实际开关结构写熄灭方式，不强加金属盖。露天广场不能无依据出现巨大室内长混响；主观放大可很近很干，压迫来自背景退去而非总音量最大。

可直接编译的一句：
> 打火轮擦动的短促颗粒声与手部动作同步；火苗稳定的一刻，进入人物主观听觉，远处人流与风快速退到近乎不可辨，只留下被刻意推近的微弱燃烧声。其他人仍按客观声场行动，不对这层放大作反应。合盖后燃烧声停止，短暂相对静默保留极弱室外底，人物抬眼时恢复广场原有声场。

“火焰占满广场”可以保留为导演意图，但必须由上述可听过程实现。

## 6 迁移到其他短剧场景

| 场面 | 层次设计 | 与剧情/连续性的关系 |
|---|---|---|
| 杯底落在石桌 | 杯与石材的短瞬态在对白停顿中清楚，液体与衣料为次层，房间底不断 | 落桌一次只响一次；玻璃/瓷器/金属按资产区别 |
| 关门后两人独处 | 门外脚步和远声随门扇闭合变闷变弱，门锁扣合后保留室内气流/衣料 | 门缝与材质决定隔声；不自动让角色听清门外低语 |
| 空走廊的来人 | 先有方向明确且有依据的远脚步，接收者停下，再显露来人 | 声先画后可建立期待，不新增不存在的人 |
| 宴会近距离交流 | 远人群为无语义底，对话近层；一次停顿让衣料/呼吸可辨 | 不在每次暧昧时全厅静音；不以大声喘息代替表演 |
| 抽剑与落地 | 剑鞘材质摩擦、剑运动的空气声按动作幅度选择，命中与物体反馈按相位 | 声音不能提前证明未发生命中；不把普通拔剑都做成巨响 |

## 7 写入现有九栏

- 本场导演设计：写核心听觉变化与其戏剧用途；声音可以先决定切镜，不等摄影写完才补。
- 生成任务：保持原声音权限，说明环境/动作声可做叙事性层次设计；不新增有语义声音或配乐。
- 场景/道具：真实声源、空间形状、遮挡、材质与打火机等结构；不是新增第十栏。
- 逐镜声音/人声：用一至数句完成“触发—声源/质地—远近与主次—变化—接出”，发生对白时保留逐字原文和可听范围。普通镜可简写稳定底声及当前动作，关键声音镜须完整展开。
- 本段锁定：记录未完发声/尾响、听觉当前是客观还是主观、哪一声层未恢复。下一段不能重启同一句或忘记恢复点。

只有生成Prompt时用可听语言；用户要后期方案时再给轨道划分、自动化和可调整的起始参数。没有实际试听不得声称已混音验证。用户要求原生生成难以精确实现的声音时，保留意图并明确后期实现步骤，不偷偷删除设计。

## 8 验收

来源、动作结构和时点一致；原话未改、声音类型不漂移；所有反应来自片内可听信息；主观放大不扩大真实可听范围；背景抽离有进入和退出；静默类型不自相矛盾；空间透视不随反打随机跳；音效不盖关键字；没有新增无依据声源/音乐；数值为设计而非伪实测；仅文字核对不称已完成声音成片。

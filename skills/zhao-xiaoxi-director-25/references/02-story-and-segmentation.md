# 读本、叙事设计与合理拆段

原文/推断/导演实现的分层、概括句拆成可拍事件、身体动作与补充权限见17。声音应在节拍阶段按19参与设计，不能等镜头完成后只附音效清单。

## 1. 从故事开始

读本按作品层级做决定。整剧确认世界、人物关系、不能提前揭晓的事实和可延续的美学。目标集明确关系或局势从哪里走到哪里，标出促成变化的原句或动作。回到场内，核对当前人物、原声、场景、人设与道具，继承上场状态和用户指定的首尾镜。连做多集时对读相似场面：同一地点可因人物关系变化而换构图，也可有意保留同一机位展示差别。

从导演的问题发想：“这场最值得留下的瞬间是什么？我想让它长成怎样的一幅画？”先排演员：两人原本各在做什么，谁希望对方做什么，听到哪句话后哪项原本持续的动作改变。将关键姿势排得可演，再选机位。举例：对手要把文件退回，手已推到桌面中线，林岚还留在椅背；镜头留住两只手之间的空桌面，直到她决定接回。例中动作只用于示范。

不要把怀疑变知道、暗示变确证、威胁变执行、命令变命中。新增看见某物的反应也可能新增知情。

## 2. 五层结构

| 层级 | 判断依据 | 不应误解为 |
|---|---|---|
| 场 | 连续时间与可连续空间的戏剧行动 | 换景别即换场 |
| 戏剧节拍 | 目标、策略、信息、力量或行动阶段改变 | 自然段或每句台词 |
| 生成段 | 一次模型任务可完成的制作单元 | 每段必有独立钩子/完整起承转合 |
| 镜头 | 两次剪辑之间连续的摄影机观察 | 一镜只能一动作 |
| 镜内节拍 | 同镜内注意力、调度、声音、表演变化 | 偷藏的切镜或瞬移 |

一个30秒段可含多个节拍；一个重要节拍也可跨生成任务。跨段保护台词、动作相位、身份和剪辑连续，不为段尾高潮提前揭密。

## 3. 信息与情绪

| 信息模式 | 关系 | 拍法机制 |
|---|---|---|
| 受限视角 | 观众和主角同步发现 | 先触发再揭示，不提前露证据 |
| 悬念 | 观众知道主角未知风险 | 先给必要危险信息，再回到不知情行为 |
| 惊讶 | 暂时隐藏新信息 | 保留可回溯合理性，到点才显露 |
| 反讽 | 观众理解双重意义 | 知情/不知情反应对照，不强制每句双方出镜 |
| 关系重排 | 控制权或策略变化 | 构图重心、谁等谁、谁留谁走随之变化 |

同场不要混用所有机制。文学剧本可内部比较两种真正不同的视听路线再选一；仅在用户要求或取舍改变观众理解时展示备选。

钩子可为未完成动作、异常关系、声音打断、问题，不必三秒内叫喊爆炸。段尾可停在反应、未完动作、结果或悬念；中间生成边界不必伪装成集尾。

### 将导演判断串成主方案

把排好的戏放进已确认的场景。取一处桌边、窗、人流、支撑或道具，决定第一幅画怎样组织脸、手、空处或背景；人物或摄影机一动，光、遮挡、焦点或间距怎样改变；在哪个动作上停下、切走或留住余波。选择真正参与本场表达的变化，已有指定首镜则从该镜发想。“本场导演设计”交付选定的拍法，让人知道重要瞬间将落在哪里。随后复查观众能读出什么、角色到这一刻实际知道什么，纠正提前揭密与无因反应。

关键揭示比较“信息源先出现、接收者先出现、连续显露”时，分别问：观众何时知道、角色何时知道、对手何时察觉角色已知，悬念或共情因此怎样改变。三者不一定都是本剧情允许的方案；以原稿冻结的揭示阶段和知情关系筛选，不把尚未证实的猜测拍成事实。反应先拍可以让观众暂不知刺激来源，但角色必须已经实际接收到刺激。

发现类场景先确认线索是否足以支持角色判断。睁眼、微笑、接礼物等单一行为不能自动证明视力、背叛或共谋；需要原稿依据。改变观看顺序时检查是否意外让双方互相发现秘密。

## 4. 时长预算

先估原台词的自然时长，同时登记动作、重要听者接收与情绪余波的必要观看，再排并行和顺序关系。普通中文约3—4字/秒、英语约2—2.5词/秒仅作初排；哭腔、犹豫、气喘、停顿、专名需更慢。有实录则以测量为准。

本段时间约为：顺序任务总时间 + 必要停顿/辨认/余波 − 确认可自然并行的部分。

硬切本身不需要额外空白秒数；需要留的是重新识别和完成动作的时间。不要每镜机械加“切镜损耗”。

可并行：短对白+稳定步行、环境声、原句尾音跨入独立听者画面；只有取景、焦点和时间均足够的反应才计入并行覆盖。应分离或延长：精细交接+多人抢话、快速转身+可读屏幕、长哭诉+多次接触、变形+环绕+新增多人入画。

时间码相加正确不等于拍得完。逐镜默读台词，预演准备—执行—结果—停稳，检查信息可辨认时间；无音频工具时明确是估算。

超载时先调整声画分工、删重复覆盖／装饰并重新分配停留，再评估不损失必要观看的并行与切镜；仍冲突按10处理固定段数／时长。不得优先牺牲重要听者反应，不删台词／关键结果、不抢读。

本skill制作段固定30秒；指定三段即90秒。不把原文长度不足当作删台词或任意缩短生成段的理由，按必要动作、反应、信息辨认组织节奏；确有时长冲突按10处理。需剪辑余量时，生成总长可以更长，但另标使用范围，不能把余量计入成片长度。

## 5. 切段边界

优先完整语义、可读结果、交接完成、接触稳定/解除、人物到位、时空转换。动作中切也合法，但要共同动作相位及匹配参考。

避免首次触碰不清、物品刚离手、不可逆结果未辨认、单词中间、口型归属不明、遮挡期间身份位置未确认。

镜头覆盖≠成片重复：两次生成可拍同一次动作的小段重叠供剪辑，成片只用一次；下一段不重复拿取、开门、打击或台词。

拆段记录：原文范围、功能、台词范围、关键动作、预计时长、起终状态、切点理由、资产缺口。先拍法，后镜数。

## 6. 镜头取舍与补镜

先读12的导演执行流程、拆镜判断与补镜矩阵。角色反应、无人空镜、环境建立、连接动作、物件细节、视线对象和声桥按必要观看与情绪／关系表达选择；运镜首先是镜内组织手段，只有独立连续观察任务才另起补镜。

镜头有信息、关系、动作阶段、反应、空间、道具、情绪停留、时间转换或声音连接功能即可。沉默不等于空，环境镜不必一概删除。

先列出本段必要观察：叙事动作、说话者意图、重要听者反应、关系变化、关键接触与结果。分别比较连续观察与独立镜头的表现力，选更能让观众看清、感受到的方案；反应与细节镜可以主动设计，不以原镜无法拍摄为前提，也不以减少镜数为优化目标。合镜须通过12的四项观看检查，不把所有观察默认挤进原镜。

补镜卡：精确插入点 → 缺口 → 主体/对象 → 开始状态 → 主要推进 → 结束状态 → 前后接法 → 影响范围。区分必补、建议、可选。

同时给出所需时长与预算来源：补镜是替换原来无用的覆盖、与现有对白并行，还是占用已有余量。不能在固定30秒之外悄悄加镜，也不能挤掉接收／余波去凑新空镜。

新增偷听、触碰、对视、读屏、关门隔音或交出证据可能改变知情/关系，检查授权。删除原剧明确动作不是普通删重。

### 常规30秒短剧的拆镜与反应覆盖

先排原句、不可省略的动作、接收和余波，再用镜头数检查密度。常规多人物冲突可参考约8—12镜；连续等待、完整行动或密集交锋各按表演时间取舍。未见关键反应就增加覆盖，切碎连续表演就合镜；用户指定镜数时优先执行，并指出确实无法兼得的时长冲突。

不能仅增加镜数后仍连续复制同眼高固定头像。逐段比较关系镜、动作／细节、单人反应与有动机的跟移、摇摄、推进或拉退：运动要改变观众获得的信息或距离，写启停与路径；全部固定也须有本段观察策略依据，不把静止当成生成保险。音效从实际材质、接触、步行及既有空间声源选择，区分声源远近和遮挡，不为了热闹加门内证据或新增对白。

逐段先排“事件／说话者的行动—重要听者接收—对手策略变化—动作连接／结果”，再写镜号。关键羞辱、威胁、支持、拒绝或证据变化优先考虑独立单人反应；按角色实际代价选择最需要被看见者，不平均给每个人一张。至少检查当前有反应价值者是否得到可读画面与时间；没有必要反应时不凑配额。反应要写刺激、视线对象、维持意图、压不住的变化及余波，不能只写“震惊”。说话者原句可L-cut延续到听者，台词只发声一次。

每个拟合镜实际预演：该机位能否看清所有必要对象？是否要同时看两个方向？从脸移到手时是否丢掉一次性反应？运动结束后是否还有完整发声和接收时间？若任何必要观察不能成立，立即拆成另一镜或几个镜头，不能只补“缓摇／转焦”保住原镜数。接近、伸手、接触、解除、结果可按观看需要分镜，但同一动作不得重演；必要命中和交接不能切没。

常见过载：“她走近、拿手机、输入、读屏、说长句，同时父亲愤怒、对手退步”应分配走位关系镜、手部操作、说话者近景和关键听者单人反应，按因果组合；不能用一个中景加“所有表情清楚”包办。不是每个动作都必须切，但每项必须看见的事件都要有真实覆盖位置。


## 7. 长镜与切镜

选长镜：真实等待、关系在同空间内可读、注意力可经表演/调度/对焦交接，连续时间增加压力。允许固定机位长镜，不因长而强制移动。

选切镜：可主动让听者情绪、共情、关系评价、压力或细节质感独占注意；也用于信息在不同方向、面部与细节需分别清楚、剧烈动作分阶段、视点改变或时间省略。长镜不等于便宜，多镜不等于高级。

动作戏先明确执行者—目标—路径—接触/释放—介质反馈—结果—落位。速度感来自方向、动作相位和声画节奏，不来自删掉命中。超自然动作服从既定世界观。

## 8. 把镜头拆分落实到新版逐镜结构

先确定每镜承担的新信息、情绪余波、关系评价或观看经验，再选景别/机位；摄影行给出拍法，完整描述给出动作、画面和表演过程，简写必要位置变化，声音栏完成归属。空镜、叙事、反应、串联、细节都是功能，不是每段必须各凑一镜的清单；环境为主且有人物的镜头写“环境建立镜／带人物氛围镜”，不误称无人空镜。

- 一个镜号覆盖一次连续摄影。正文出现“切至俯拍”“反打”“再切特写”时，分别起镜号；固定机位内转头、移焦、连续推拉摇移不自动拆镜。需要概括多镜关系时，放在“本场导演设计”；正式镜号内只写这一条连续摄影。
- 用触发、执行、结果、反应、接续检查必要信息，不把五项机械拆成五镜。精细手部动作与读长台词无法同时清楚完成时，分镜或错时；不以一秒塞入多次眼神、抿唇、转身和位移。
- 把原台词、关键动作、必要辨认与重要听者的接收／变化／余波共同纳入预算；制作段固定覆盖0—30秒。时间码相加正确仍需动作预演，避免为新空镜挤掉完整对白。
- 对已有视频可据镜头组标注；反推制作Prompt时，拆成可执行镜头并标出哪些是原片观察、哪些是新设计。不要把剪辑字幕、工具分析或模型推测当作已听清的声音。

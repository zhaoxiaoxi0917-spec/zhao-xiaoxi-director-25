# 制作、剪辑、返修与学习

## 1. 资产决策服务剧情

先列关键身份、场景结构、道具形态和必须跨段稳定的状态，再判断已有素材足不足。人设图、空场图、道具图、多角色关系图和走位白模各司其职；不强制每个项目先做全套。

参考是否缺失，用具体后果说明：门的方向未知会影响出入画接口；衣领标记未知会影响身份识别。不是“参考图越多越稳定”。没有实际提交平台时不报虚构上传成功，也不在生成Prompt中伪造引用。

复杂空间/穿行可建议白模或走位视频，拍法和人物身份参考分开。环境空板、关键动作覆盖、听者反应和细节素材只在正片/剪辑有明确用途时补，不批量制造无用安全镜。

## 2. 生产顺序与剪辑接口

剧本顺序、生成顺序和剪辑顺序可以不同。按同角色/同场景批量制作能减少设置工作，但每次仍带入各段正确时间状态，不把上一条生成结果误当本条剧情前情。

生产单可列：稳定段号、剧情位置、资产版本、输入状态、生成时长、计划使用区间、关键风险、输出状态、依赖段、验收状态。只在批量工作中展开，不拖累单镜任务。

需要剪辑余量时，留在有用的位置：动作前的稳定起态、动作后的可接反应、声桥所需环境声。不规定每段最后三秒无台词，也不默认每镜加若干秒。余量计入生成时长，与最终采用时长分开计算。

跨段最少交接：人物可见/声源、物理位置与朝向、手位/接触、道具归属和损坏、衣物/伤势、光源状态、正在进行的动作、情绪策略、前一句声音是否未完。非持续状态无需重复整个剧本。

选定上一段实际成片后，将“计划终态”与“可接受的实拍终态”比较。偏差影响下段时，先决定修上一段还是获准更新连续性，不默默让计划与成片各用一套真值。

原生对白无法靠无说明加速画面解决。需要重定时、后配音或拆轨精剪时，说明对口型、节奏、声音质感的影响。AI素材仍应按镜头/声音功能审片，而不是只检查分辨率和有没有出图。

## 3. 风险优先的小样

写Prompt可以直接完成，不以“必须先付费试生成”阻断。用户授权实际制作后，优先测试成本高或叙事不可替代的假设，例如多人接触、能力命中、参考冲突、长句口型、连续穿门。费用与耗时依据平台实际信息，不编价格或成功率。

小样回答一个问题，固定其他条件，留原版与变体。结果只支持该模型/平台/素材/版本下的结论，不因一次成功就宣称普适，也不因一次失败把手部动作永久禁掉。

## 4. 先定位，再返修

有视频时找首次偏离目标的时点及可见/可听证据；只有截图只判断该帧，只有用户描述注明依据，不声称已审片。

| 根因类别 | 证据线索 | 优先处理 |
|---|---|---|
| 剧情事实 | 人物提前知道、动作阶段越级、换台词 | 恢复当前事实和触发顺序 |
| 资产/引用 | 串脸、服装/道具参考互抢、假引用 | 分离用途、纠正绑定与版本 |
| 空间/接触 | 抓空气、不可达、穿桌、反打跳位 | 重建可达布局、显式接触锚点、机位换算 |
| 时间/并行负载 | 台词未完就切完动作，命中被挤掉 | 重排先后、给时间、合理拆段；不削弱结果 |
| 指令冲突 | “固定”又“环绕”，初态已写终态 | 删除冲突命题，重写完整受影响段 |
| 表演与剪辑 | 情绪推早、尾音未落就切走、相同距离轮流拍脸 | 找到原句中策略改变的位置，调反打或停留，核对整句仍只发声一次 |
| 画面质感 | 同一光区里脸、布、金属呈现相同亮面；参考首帧本身已磨皮 | 比较原参考、首帧和运动后的同一表面；按实际证据调整资产、入光方向、曝光层次或取景距离 |
| 运镜与空间 | 侧移经过柜门后丢失关键接触，情绪反应落在遮挡后 | 从首次失去必要画面的位置回推，改路径、减速停稳或重定切点 |
| 随机波动 | 输入一致但结果波动，无稳定文本证据 | 记录假设，授权后受控复测，不虚构根因 |

“更自然、更高级、不要出错”不是根因修复。先写能实现目标的新因果过程，再决定是否有必要保留针对性否定词。

## 5. 状态性返修

用户说取消一个动作时，清理它的准备、发生、声音、结果及后续依赖。比如取消摔杯，不仅删除“摔”，还需检查提前抬手、碎裂声、地上碎片、割伤与下段扫碎片动作；若割伤另有冻结的剧情作用，指出冲突并询问，不擅自取消。

用户要求保留一次接触时，近景仍需保留可识别的被接触局部。调整构图或拆覆盖镜，不能为了“画面只有主角”让接触对象消失。

只改一镜：给可直接替换的一镜和必要接口提醒。要求修改完整版：输出重建后的完整目标段，确保旧命题不残留。保持稳定段号/镜号；新增镜可用后缀或明确新旧对照，不无故连锁重编号整剧。

不要覆盖或删除用户原资产；明确版本。未授权的改法列为建议。多聊天框交接必须包含当前有效稿、真实参考标签及用途、冻结事实、当前状态、已弃用动作和待验证项；不能只说“按导演框的最新版”。

交付前加查：本镜三重站位是否齐备且由同一空间推导；运动后位置是否被后镜和邻段继承；关键表演是否被镜数挤占或藏在过载的长镜中；重要听者的反应是否可辨；单镜是否藏了多个不可实现的观察；面对面是否被误排成双正面头像；美学是否仍只报片名；跨段是否近似重复硬接；运镜、景深及真实声源是否落实。发现任一项，重排受影响镜头和时间，不在末尾追加禁令假称修好。

## 6. 验收与学习记录

文本检查能确认结构和约束，不能测出真实口型、受光或表演。实际成片按以下优先级审查：

1. 事实、台词、身份、动作结果是否正确。
2. 因果与空间是否读得懂，接触与物理/设定行为是否成立。
3. 表演是否在对人做事，情绪变化是否被触发；重要听者的接收、变化与余波是否在实际取景、焦点和时长中可读，背景虚影或扫过侧影不自动算覆盖。
4. 镜头、光影、声音是否服务本场，剪辑接口能否使用；合镜是否丢接触／表情、移焦是否漏事件、异向重要事件是否争夺注意，不能因镜数变少就判优化成功。
5. 细节瑕疵是否影响可用性；区分必须重做、可剪修、可后期修与可接受。

测试记录最小字段：模型/平台/日期、素材和Prompt版本、期望、观察证据、单一主要改动、结果、适用范围、未验证部分。修复验证后还检查台词/剧情/邻段是否回归出错。

经验先归本项目；只有跨场景证据支持才提炼为候选通用方法。尊重用户是否授权更新技能；不把单次返修自动写入永久规则。技能文本前向测试、模型实际生成测试、成片审查是三种不同证据，必须分开声明。


### 独立复核与缺陷闭环

完成设计后，另作一次从原剧本、当前有效素材和状态底稿出发的复核，而非只重读新Prompt。先遮开设计理由，对照事实和状态，再检查观看效果；不要求另一个agent，也不以“做了两遍”代替具体证据。

内部为原对白与会影响剧情的电话、撞击、警报等声音分配稳定事件标识，登记原文／声音类型、发声者或声源、顺序、次数、落镜、跨镜延续及谁可听见。拆镜后同一事件仍是一次，不能因跨段重新编号而重复；普通呼吸、衣料和环境底噪按需要检查，不逐项强制编号。事件标识不进入可见字幕或朗读内容。

缺陷最小记录：集段／镜号或时间点 → 原始依据 → 期望与实际差异 → 根因或待证假设 → 修法 → 受影响字段和后续段 → 复查结果。仅有文本就明确“文本差异”；未提供视频不虚构实拍证据。

P0：改变身份／对白／剧情结果、破坏空间因果、跨段状态或关键光影事实的错误，交付前必须解决；P1：不改变事实但让重要表演、视听设计或信息可读性不足的问题；P2：不影响必要观看的修饰。按实际后果分级，同一种技术不固定归一个级别。必要反应丢失会破坏剧情理解时同样升为P0。

修改后沿状态依赖检查后段，直到被改字段不再被使用或被有依据的新事件覆盖；核对前一镜接口和下一镜输入，保留未受影响内容。记录未解决项，不用全局“保持一致”标记为通过。文本规则检查、前向试写和实际视频验收分别报告。

### 用真实任务检验规则能否迁移

获准建立或运行案例时，优先选择不同问题的原始材料：秘密揭示与伪装、多方对峙与身份相似者、关键接触与持物、跨空间动作、奇幻变化。记录完整原文或明确可核实范围、真实素材作用域、冻结事件及知情、允许设计的范围、时长与输入／输出状态。未取得完整剧本时，只称摘要教学假设，不宣称还原某部作品。

验收检查事实、必要观看、动作／状态接口及设计依据，不把某套镜号、镜数或唯一拍法当标准答案。比较不同有效方案的观众体验；保留暴露失败的材料和修后结果，避免只挑容易案例。文本前向试写与实际生成测试分别记录；没有素材或生成授权时不补造图片、不收费试片。案例方法归入现有模块，不另建与主流程并行的导演引擎。

## 7 日常返修交付
本skill返修默认输出完整目标30秒段，除非明确只改某镜。人设、场景、道具继承当前有效稿，只有人设栏沿用原@一次；其他位置用<EnglishName>。群像不机械拆号，站位集中锁定；完整稿不能写“其余同上”或新增资产绑定。批量按集独立等质量交付，执行10。

## 8. 串人与跳位故障的定位

按13先核对标签是否属于当前素材组、真实输入是否可核实、资产用途是否混用、逐镜角色和背景是否明确，再核对发生偏差前后的状态。没有看到实际请求与成片，不能把故障单独归咎于模型或参考顺序。返修先消除文本可证矛盾；需要参考上段时只采用已验收帧/片，不传播错误脸和站位。仅在现有授权内做媒体操作，不自动付费试片。

## 9. 独立返修与画质保护

先选修复层级，不默认垫图：切点／冗余先检查可否剪修；缺反应独立补镜；单镜身份或道具错从原始清晰资产重建；站位错误若影响接触、背景和后续路线，从首次偏离点重建必要连续单元。交付仍按用户要求给完整替换段，实际重生成范围不必等于整段。

参考按用途登记：原始人设负责身份，服装／道具资产负责形态与状态，场景板负责结构，已验收帧负责获准构图／动作相位，失败截图只提供定位证据及其中明确采纳的正确字段。不可把错误坐姿、背景或持物随一张正确脸的截图一起继承。保留原始文件与版本，避免把聊天缩略图、拼图小图、多次转存图或已变形返修图作为唯一画质母版。

结构返修需要垫图时，先由原始清晰资产重建目标状态，核对身份、空间前后、接触、数量、光向与构图，再进入视频制作；不要求每次都垫图，不自动生成或收费试片。实际平台支持的参考方式按01核验。发现参考已明显模糊、变形或结构错误持续传播，停止在该结果上叠加修补，回有效原资产。像素尺寸与有效细节分开判断；放大不能保证修复脸、手、空间或恢复丢失细节，没有原始输入和成片不能断言退化来源。

独立返修检查：失败镜是否可恢复人物、真实背景、起终态、手位接触和声轨接口；修复是否会改变相邻镜必需状态；未受影响镜是否可保留。原台词／动作事件只发生一次，补镜不重复声音或结果。文本检查、前向试写与视频验收分别报告，不把提示词检查通过说成画质已提升。

# 场景、调度与连续性

## 1. 场景图不是三维测绘

先看图片，分开可见事实、透视支持的推断、画外未知。单图未显示的门/通道/反打墙面不能写成已证实。尺寸无依据时用一臂、相邻座、桌侧通道等相对尺度；精确距离仅为明示设计值。

检查时代地点、日夜、门窗墙体、固定家具、通行区、纵深、主光、镜面、文字和多角度一致性，再把剧本动作放进场景试走。

| 兼容级别 | 处理 |
|---|---|
| A直接支持 | 用可见锚点设计 |
| B缺非剧情性画外信息 | 明示最小布景假设，维持已知结构 |
| C机位/路线不可用 | 改合法机位、裁切或覆盖，不改剧情 |
| D影响目击、逃生、秘密、结果 | 指出冲突，不偷偷加门、监控或证据 |

无场景图且要求完整创作时，可提出布景方案，标明是设计而非观察事实。已有场景不随段重建。

## 2. 调度从关系出发

每次位移回答：为什么此刻移动、要改变与谁/什么的关系、对方怎样响应。走近可为请求/施压/试探，退开可为拒绝/让路/诱导；不能只用走动制造活力。

排演每次相互作用：从该角色的位置，他看得见触发物吗，听得见说话人吗，伸手够得到对象吗？例如摄影机可同时取到前方帮厨与后方伯爵的手势，帮厨仍要先转身看到手势，才能停步；不能靠剪辑替演员获取信息。调度写起点、触发、真实路线、终点与到位后的任务。

静止也可施压。不要强迫每镜空间事件、每段距离改变或位移归零；仅剧情需要返回时回原锚。

## 3. 三重坐标与射线

1. 物理：房间中的位置、距离、姿态、朝向、左右手与固定对象。
2. 摄影机：侧别、高度、朝向、动作/对话轴关系、移动路线。
3. 画面：该机位导出的左中右、前中后、高低、遮挡、视线与负空间。

人物右手不等于画面右手。换机位后重新换算，不改变真实座位；同时维持轴线可理解性。

射线：摄影机 → 主体 → 主体身后背景。人物面对窗，摄影机从窗侧拍正脸，背景通常是身后室内，不是其面前窗。视线对象可在摄影机后方，不必同框。

本工作流默认不越轴，反打与运镜均留在已锁允许侧。剧情造成新关系时先拍清人物真实朝向与新轴，不能以“有艺术目的”自行翻转；只有用户明确允许时才设计跨轴观察，仍须交代空间。

### 输出中的三重站位（采用用户定义）

上述物理／摄影机／画面是内部校核系统；输出采用三类可见位置，不能互相替代：
1. 画面方位：以观众看到的边界为参照，画左、画右、左下、右上。它不是场地里的东西南北。
2. 相对空间：谁在谁上方、门外、桌沿外、栏杆后；明确距离、支撑及遮挡对象。
3. 镜头层次：前景、中景、背景，说明局部和主体之间的纵深。

站位调度先锁物理底稿，各镜按新机位核对三重站位。正文用可见的关系自然落实，单人或局部镜只交代有辨识意义的方位、视线对象与支撑；换边关系、关键接触和新落位要写得可核对。人物单人近景可裁掉对方，但必要接触局部必须保留；有台词或动作的画外角色注明所在位置与声音归属。

镜头射线仍须检查：摄影机→人物→背景。身高由同地面比例及支撑证明；站桌者下桌后重新校核视线高度。参考图只约束实际可见的站位、身份或质感，不把图中的牵手强制延续到抽手后，也不凭单张图认定全场方位。

### 多人主轴、副轴与镜头转换

主轴按当前主行动／对峙双方建立；有人转向第三人时，另登记该次对话副轴，不能因一直写“轴西侧”就认定所有关系都正确。每次换观察对象检查：实际说话者与听者的位置／朝向 → 当前关系轴 → 可用机位 → 两人在该机位下的视线与画面方向 → 与前镜的方向衔接。内部只在关系改变处记录，不把几何表塞进每镜。

人物不动、仅转头时，物理落位不变；新副轴不能授权摄影机穿墙或角色换边。若机位对主轴合法、对新对话关系却造成方向误读，先用已有空间内的关系镜、明确的视线对象或连续重构图建立新关系，再接单人。用户明确禁止越轴时，只用符合该要求的机位／重新建立方案，不以艺术选择绕过限制。

遮挡可用于延迟揭示；检查被遮住的是尚可延迟的信息，还是此刻必须辨认的接触、身份或反应。不能一律禁止遮挡，也不能把重要人物的模糊背景当作必要观看已完成。

### 逐镜执行三重站位与运动落位

先固定左右的参照系：用户已给基准观察方向或采用站位图时，“某人左边／右边”按该基准画面的空间区域继承，除非明确说角色自身左手／右手侧。不能把门口基准画右的人改放到守门者身体的右手侧；人物转身不等于站位左右翻转。换机位后只重算新画面投影，原基准区域仍不变。没有基准且歧义会改变堵门／接触／通路时，先从现有图文恢复，不能自行选人体左右并冒充已锁定事实。

关系镜示例：“甲在画左前景、桌南侧，面向画右后景桌北侧的乙；桌面隔在二人之间。”单人反打示例：“甲位于画面中右的前景近层，仍站桌南侧，朝画右外的乙看；身后为南墙，乙在画外桌北侧。”细节镜示例：“甲右手从画左进入中景，握住位于画面中央、桌南沿的手机；桌北侧文件夹只留后景边缘。”例中方位仅适用该已建立机位，不跨场套用。

每次运动后连同未移动者一起重算相对位置。例如女主向门前移半步、母亲未动，母亲应从女主原左侧变成新落位的左后侧；不能又写“母亲保持原地”，又始终把她贴在女主身旁。用固定门框／桌沿／原落点作为锚，再推导新的画面与相互距离，不能只锁运动者而漏掉其他人的相对变化。

位移必须给起点、触发、可通行路线、终点、身体朝向与手位；到位镜尾立即更新三重站位和主／副轴，下一镜及下一段从新落位开始。摄影机移动与演员移动分开描述。换机位要重新投影画面左右与层次，演员未走就不能因反打换边；人物退出取景仍保持真实画外位置。面对面主轴与第三人副轴分别检查，默认全段不越轴，不能借单人特写偷偷换到轴另一侧；确需改变观察侧须先设计可理解的重新建立，用户未明确允许跨轴时不安排跨轴运动。


## 4. 动作与接触

复杂身体动作、舞句或“动作僵硬”返修加读17：承重、发起、身体各部位先后、运动路径、制动/落稳和余势都与本节的接触状态对应。轻触、借力和实际承重分开，不固定一种转身顺序；必要连续动作仍须兼顾重要反应覆盖。

反查前提：有物可拿、手有空、距离可达、支撑存在、路线不穿墙、受力有落点、结果有原因。

接触状态：谁的哪只手/部位 → 接触谁/什么的何处 → 握/扶/压/抱/贴方式 → 开始/保持/解除 → 解除后位置。不能混写抓住和悬在附近。

拥抱/压制/搀扶已确认时，用对方必要局部、双人构图或接触特写保留关系。裁切减可见范围，不删画外身体。

跨镜保持动作相位，不重置准备。裂开、湿润、落地、熄灭、伤势在发生后才生效，持续至合法恢复。

分清命令、准备、执行、命中、结果；不能从命令推断执行，也不能从尚未命中擅自补开火准备。以剧本真实阶段为准。

### 动作切点的相位交接

在拿取、递交、抓握、解除、推拉、命中等关键切点，内部记“前镜切出相位 → 后镜切入相位”，加持有人／手位、运动方向及结果。示例：右手已握住手机、刚离包口 → 同一右手继续抬升；不能后镜再伸手取一次。接触尚未解除就切到脸时，接触在画外仍保持，后镜不得自动变成双手自由。

动作匹配可以有为剪辑服务的极短覆盖余量，但成片中同一次动作只发生一次；不能用重复发声、重复命中或回到准备姿态冒充连续。允许省略非必要路程，须保留可理解的路线与时间依据；关键接触、交付和剧情结果不能因省略而消失。

## 5. 在场、入画、发声

逐镜管理：在场、可见方式、发声类型、口型、动作权限、参考使用、画外状态、可听可知内容。

- 在场不等于每镜有肩膀/倒影；画外不等于离场。
- 后镜出现的人物资产可属于本段集合；不要假装平台能按文字逐镜卸载文件，通过当前可见者声明分配职责。
- 画外说话不自动增加可见人物；接触对象不是多余人形。
- 群体按功能分层，反应有触发/传播，不新增有语义台词。

## 6. 典型场面

门口：开合方向、操作者、跨槛先后、门后空间、离场后可见性。普通脚步可有清晰时间省略，关键目击/偷听经过不能省。

餐桌：桌形、座位、邻座、道具与通道；过肩尺度符合距离；不能隔桌穿体接触。

车辆：左右舵、座位和门先定，再定前后侧机位；不以镜像画面推断物理方向。驾驶、车速、道路不能被聊天覆盖。

通话：两个空间两套轴与光。只拍一端合法，尤其需隐瞒身份时。可听者由听筒/免提/耳机决定，旁人不能无依据知情。

反射：判断真实方向及应出现的人/光，不一律无倒影同时要求真实镜面。可避开高风险，但不能删镜像证据。

幻想/微缩/巨人：按已定比例能力设计接触、落脚、视线高度、力量和环境反馈，写实质感不等于普通人体能力。

### 跨段同时锁状态与剪辑接口

整集先排所有段的输入与输出，再逐段精写；每个段界内部记录“尾镜主体／景别／机位与方向／动作相位／声尾 → 首镜对应项”。可从同一机位接住未完成的动作，也可由视线、动作或声尾切给新的主体。若近似构图的硬接造成跳动，调整剪点或角度；连续的构图若保住一段完整等待，就维持它。

补镜要接收上一段已经发生的事件，持续动作只推进一次，原句声尾不重复起句。继承身份、衣物、持物左右手、接触、门灯与家具、移动后的落位、知情和情绪；更换首镜不代表连续性已经通过。接口必须在两段正文实际成立，不只在结尾写“保持一致”。


## 7. 接口

从实际镜尾提取位置姿态、朝向、双手/接触、道具、门灯、情绪策略、知情、未完动作、声音尾巴与动作相位；下一段重写成自足开场。

有依据的画外事件/时间省略可更新状态并注明依据，不要求所有微小变化补镜；用户要求看见的关键结果不得省略。

在事件后刷新状态，不固定第15秒停顿。只维护一份当前状态，栏目间不能各造数值。

## 8. 身份与场景的实际执行

涉及身份、站位或跨段时先执行13：同一底稿维护真实引用作用域与识别点、场景定位物/地面/灯态/可用机位、每段输入—事件—输出。画面左右从实际机位推导，近景不改变人物位置。每镜明确当前主体、接触局部、声源及其身后真实背景；单人反应不能靠通用“她震惊”承载身份。场景图某部分错误时按用途分项采用，不能整张照抄。


逐段身份核对：同一场景维护唯一姓名—亲属角色—真实人设引用—服装识别点映射；父亲、哥哥、丈夫与相似衣着女性分别登记。每镜用姓名明确行动者、听者及持物者，重新出镜或易混处追加当前素材的简短识别点。不能为构图换衣、换脸或把IP编号当作不同素材组通用的人物身份。
